# 네트워크 구성(Network Configuration) 정리

## 1. 네트워크(Network)란?

네트워크란 여러 컴퓨터와 장치들이 서로 연결되어 데이터를 주고받을 수 있도록 구성된 시스템이다.

예시:
- 인터넷
- 학교 전산망
- 회사 내부망(LAN)
- 와이파이 공유기 연결

---

# 2. 네트워크 구성 요소

## 2-1. 호스트(Host)

네트워크에 연결된 장치들을 의미한다.

예시:
- 컴퓨터
- 스마트폰
- 서버
- 프린터

---

## 2-2. 서버(Server)

클라이언트에게 서비스를 제공하는 컴퓨터이다.

예시:
- 웹 서버
- 데이터베이스 서버
- 파일 서버

---

## 2-3. 클라이언트(Client)

서버에 요청(Request)을 보내 서비스를 사용하는 장치이다.

예시:
- 웹 브라우저
- 모바일 앱
- 사용자 PC

---

# 3. 네트워크 장비

## 3-1. 허브(Hub)

데이터를 연결된 모든 장치에 전송하는 장비이다.

특징:
- 단순 구조
- 충돌 발생 가능
- 현재는 거의 사용하지 않음

---

## 3-2. 스위치(Switch)

목적지 MAC 주소를 확인하여 필요한 장치에만 데이터를 전달한다.

특징:
- 충돌 감소
- LAN 환경에서 많이 사용
- 속도가 빠름

---

## 3-3. 라우터(Router)

서로 다른 네트워크를 연결하는 장비이다.

특징:
- 인터넷 연결 담당
- IP 기반 경로 설정
- 공유기에 포함되는 경우 많음

---

## 3-4. 게이트웨이(Gateway)

서로 다른 프로토콜이나 네트워크 간의 통신을 가능하게 한다.

예시:
- 내부망 ↔ 인터넷 연결

---

# 4. 네트워크 종류

## 4-1. LAN (Local Area Network)

좁은 범위의 네트워크이다.

예시:
- 학교
- 회사
- 가정

특징:
- 빠른 속도
- 낮은 비용

---

## 4-2. MAN (Metropolitan Area Network)

도시 규모의 네트워크이다.

예시:
- 지역 통신망

---

## 4-3. WAN (Wide Area Network)

넓은 지역을 연결하는 네트워크이다.

예시:
- 인터넷

특징:
- 장거리 통신 가능
- 속도가 상대적으로 느림

---

# 5. 네트워크 토폴로지(Topology)

## 5-1. 버스형(Bus Topology)

하나의 케이블에 여러 장치가 연결되는 구조

장점:
- 설치 비용 저렴

단점:
- 메인 케이블 장애 시 전체 장애 발생

---

## 5-2. 스타형(Star Topology)

중앙 장비(스위치)에 모든 장치가 연결되는 구조

장점:
- 관리 쉬움
- 장애 파악 쉬움

단점:
- 중앙 장비 고장 시 전체 장애

---

## 5-3. 링형(Ring Topology)

장치들이 원형으로 연결되는 구조

장점:
- 데이터 충돌 적음

단점:
- 한 곳 장애 시 전체 영향 가능

---

# 6. IP 주소(IP Address)

네트워크에서 장치를 식별하기 위한 주소이다.

예시:
- 192.168.0.1

종류:
- IPv4
- IPv6

---

# 7. MAC 주소(MAC Address)

네트워크 장비에 부여된 고유한 물리 주소이다.

특징:
- 랜카드에 저장
- 변경이 거의 없음

예시:
- 00:1A:2B:3C:4D:5E

---

# 8. 프로토콜(Protocol)

통신을 위한 규칙이다.

대표 프로토콜:
- TCP
- IP
- HTTP
- HTTPS
- FTP
- DNS

---

# 9. TCP/IP 계층 구조

## 9-1. 응용 계층(Application Layer)

사용자와 직접 연결되는 계층

예시:
- HTTP
- FTP
- DNS

---

## 9-2. 전송 계층(Transport Layer)

데이터 전송 담당

프로토콜:
- TCP
- UDP

---

## 9-3. 인터넷 계층(Internet Layer)

IP 주소 기반 데이터 전달 담당

프로토콜:
- IP
- ICMP

---

## 9-4. 네트워크 인터페이스 계층

실제 물리적 통신 담당

예시:
- Ethernet
- Wi-Fi

---

# 10. 네트워크 보안

## 방화벽(Firewall)

외부 접근을 제어하는 보안 시스템

---

## VPN(Virtual Private Network)

암호화된 가상 네트워크 연결

특징:
- 보안 강화
- 원격 접속 가능

---

## IDS / IPS

침입 탐지 및 차단 시스템

---

# 11. 원격 접속(Remote Access)

다른 컴퓨터를 네트워크를 통해 제어하는 기술

예시:
- RDP
- TeamViewer
- AnyDesk
- SSH

---

# 12. 네트워크 구성 예시

[인터넷]
     ↓
[라우터]
     ↓
[스위치]
 ┌───┼───┐
PC1 PC2 Server

---

# 13. 네트워크 구성 시 고려사항

- 속도
- 보안
- 확장성
- 비용
- 안정성
- 유지보수

---

# 14. 느낀점

네트워크 구성은 단순히 컴퓨터를 연결하는 것이 아니라,
데이터를 안전하고 효율적으로 전달하기 위한 중요한 기술이라는 것을 알게 되었다.

또한 라우터, 스위치, 프로토콜 등의 역할을 이해하면서
실제 인터넷이 동작하는 원리를 조금 더 이해할 수 있었다.
