# C 파일 입출력 학습

## 1. 개요
이 학습 자료는 **C 언어에서 파일을 열고 읽는 기본 방법**을 공부하기 위해 작성되었습니다.  
주요 예제:
- 파일 열기와 닫기 (`fileopen.c`)
- 텍스트 파일 내용을 화면에 출력 (`cat-style.c`)

---

## 2. 파일 열기와 닫기

### 핵심 포인트
1. `FILE *fp;` : 파일 포인터 선언  
2. `fopen("파일명", "모드")` : 파일 열기  
   - `"r"` : 읽기  
   - `"w"` : 쓰기 (새로 생성)  
   - `"a"` : 이어쓰기  
3. `fclose(fp)` : 파일 닫기  
4. 항상 `NULL` 체크 → 파일이 없거나 열기 실패 시 오류 처리  

---

## 3. 텍스트 파일 읽고 출력하기

### 핵심 포인트
1. `argc` / `argv` 사용 → 명령줄 인수 처리  
2. `getc(fp)` → 파일에서 한 문자씩 읽기  
3. `putc(c, stdout)` → 화면에 출력  
4. `EOF` → 파일 끝 표시  
5. 입력이 없으면 `stdin` 사용 → 표준입력 처리 가능  

---

## 4. 학습 팁
- **작은 코드로 실험**: 한 문자씩 읽고 출력해보면 입출력 동작 이해가 쉬움  
- **파일 존재 체크 필수**: 파일 열기 실패 시 `NULL` 체크  
- **표준입력과 파일 입력 모두 처리 가능** → 유연한 프로그램 작성 가능
