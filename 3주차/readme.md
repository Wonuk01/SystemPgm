# 📂 Linux 파일 관련 명령어 정리

## 📌 1. 파일 내용 확인 : cat

`cat`은 파일의 내용을 출력하는 명령어이다.

### 사용법

```
cat 파일명
```

### 특징

* 파일 내용을 터미널에 그대로 출력
* 여러 파일을 동시에 출력 가능

```
cat file1.txt file2.txt
```

* 파일이 없으면 에러 발생

---

## 📌 2. 파일 생성 : touch

`touch`는 빈 파일을 생성하거나, 파일의 수정 시간을 변경한다.

### 사용법

```
touch 파일명
```

### 특징

* 파일이 없으면 새로 생성
* 이미 존재하면 시간만 업데이트

---

## 📌 3. 실행 파일 위치 : /usr/bin

`/usr/bin`은 리눅스에서 기본 명령어 실행 파일들이 저장된 디렉토리이다.

### 예시

```
ls /usr/bin
```

### 특징

* 대부분의 기본 명령어(ls, cat 등)가 위치
* PATH에 포함되어 있어서 경로 없이 실행 가능

---

## 📌 4. 디렉토리 삭제 : rm -r

`rm -r`은 디렉토리를 재귀적으로 삭제한다.

### 사용법

```
rm -r 디렉토리명
```

### 예시

```
rm -r empDir
```

### 특징

* 내부 파일까지 모두 삭제
* ⚠️ 매우 위험 (복구 불가능)
* 강제 삭제:

```
rm -rf 디렉토리명
```

---

## 📌 5. ll 명령어

`ll`은 파일 목록을 자세히 보여주는 명령어이다.

### 사용법

```
ll
```

### 특징

* 실제로는 `ls -l`의 별칭(alias)
* 파일 권한, 소유자, 크기, 날짜 표시

---

## 📌 6. 도움말 관련 명령어

### 🔹 man (Manual)

명령어의 매뉴얼을 확인한다.

```
man ls
```

* 가장 자세한 설명 제공
* 종료: `q`

---

### 🔹 info

`man`보다 구조화된 도움말 제공

```
info ls
```

* 링크 기반 탐색 가능

---

### 🔹 --help

간단한 사용법 확인

```
ls --help
```

* 빠르게 옵션 확인 가능

---

### 🔹 whatis

명령어의 간단한 설명 출력

```
whatis ls
```

* 한 줄 요약 제공

---

## 📌 7. 파일 관련 기본 명령어 정리

| 명령어   | 설명          |
| ----- | ----------- |
| cat   | 파일 내용 출력    |
| touch | 파일 생성       |
| ls    | 파일 목록 보기    |
| cp    | 파일 복사       |
| mv    | 파일 이동/이름 변경 |
| rm    | 파일 삭제       |
| mkdir | 디렉토리 생성     |
| rmdir | 빈 디렉토리 삭제   |

---

## ⚠️ 주의사항

* `rm -r`, `rm -rf`는 매우 위험한 명령어
* 삭제된 파일은 복구가 어려움
* 중요한 파일은 항상 백업 필요

---

## ✅ 한줄 정리

리눅스에서는 파일 생성, 조회, 삭제를 명령어로 관리하며,
`man`, `--help` 등을 통해 명령어 사용법을 쉽게 확인할 수 있다.
